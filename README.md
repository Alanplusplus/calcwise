# CalcWise

CalcWise is a collection of free online financial calculators and plain-English guides for US and UK readers: mortgage, loan, savings, investing, retirement, debt payoff, tax, paycheck, and more.

**Live site: [https://www.calcwise.tools](https://www.calcwise.tools)**
**Translated Version: [English](https://www-calcwise-tools.translate.goog/?_x_tr_sl=auto&_x_tr_tl=en&_x_tr_hl=en&_x_tr_pto=wapp&_x_tr_hist=true)**

## What it offers

- **30+ calculators** covering home buying, loans, savings and investing, debt, taxes and income, and everyday money decisions. Each one is pre-filled with realistic defaults and followed by an in-depth article with the formula, worked examples, and FAQs.
- **Scenario pages** for common questions, such as a credit card minimum-payment payoff or a 15-year versus 30-year mortgage.
- **In-depth guides** with case studies, comparison tables, and step-by-step instructions.
- **Data reports** built from public datasets, for example mortgage affordability by state.
- **Embeddable calculators** that other sites can add with a single iframe snippet.
- **Sourced figures**: rates, tax brackets, and benchmarks come from primary sources (IRS, Federal Reserve, BLS, Freddie Mac, and similar), shown with an "as of" date. See the [methodology page](https://www.calcwise.tools/methodology).
- **Private by design**: every calculation runs in your browser, and no financial input is sent to a server.

## Tech stack

Next.js (App Router, static generation), React, TypeScript, and Tailwind CSS, deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000. Build the production site with `npm run build`.
